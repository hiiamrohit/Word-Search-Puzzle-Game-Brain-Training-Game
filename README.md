# Word Search Puzzle Game

A simple, fun, and engaging **Word Search Puzzle Game** designed for casual brain training and vocabulary practice. Players find hidden words in a letter grid by swiping across letters.

## 🎮 Features

- 🔎 Classic word search gameplay
- 🧩 Themed word-search levels
- 👆 Swipe to select hidden words
- ↔️ Horizontal, vertical, diagonal, and reversed words
- 💡 Hint system to help find difficult words
- 🔄 Restart/reset puzzle option
- 📊 Word-finding progress indicator
- 🏆 Level completion and progression
- 🔓 Progressive level unlocking
- 🎨 Clean, colorful, and relaxing game interface
- 📱 Simple and mobile-friendly gameplay

## 🕹️ How to Play

1. Choose an unlocked level.
2. Read the list of words you need to find.
3. Search for the words inside the letter grid.
4. Swipe from the first letter to the last letter.
5. Correct words are highlighted automatically.
6. Find all the words to complete the level.
7. Complete the level to unlock the next one.

## 🎯 Word Directions

Words can appear in different directions:

- Horizontal →
- Horizontal ←
- Vertical ↓
- Vertical ↑
- Diagonal ↘
- Diagonal ↙
- Diagonal ↗
- Diagonal ↖

## 💡 Hint System

When a word is difficult to find, players can use a hint to reveal the location of an unfound word.
